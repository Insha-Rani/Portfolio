## 🛠️ Tech Stack
- **Core:** Python, Pandas, NumPy, Scikit-learn, SQL
- **Web & Front-end:** HTML, CSS, JavaScript, React, Tailwind CSS, Vite
- **Deployment:** Streamlit Community Cloud, Replit, Vercel

## 📦 How to Run Locally or Deploy on Replit

### 1. Clone the repository
```bash
git clone https://github.com/Insha-Rani/insha-rani-portfolio.git
cd insha-rani-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
