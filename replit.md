# Running this portfolio on Replit

This project uses React, TypeScript, and Vite. The primary app starts with `npm run dev` and serves on port 5000 through the **Start application** workflow. Install dependencies with `npm install` if needed.

Run `npm run build` to produce the static site in `dist/`, and `npm run lint` for a TypeScript check.

`server.py` and `standalone_portfolio.html` are separate alternatives; they are not used by the React/Vite workflow. The portfolio itself does not require environment secrets to start.
